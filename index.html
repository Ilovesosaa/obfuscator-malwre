Every stage runs server-side, in a fixed order, on a lexer that understands Lua and Luau. Turn any pass off and the artifact changes with your settings — no hidden stages, no surprises at load time.

Source obfuscator 01

EDITING SCRIPT:

Deep source obfuscation runs AST-based renaming, constant-table packing, string encryption, number encryption and an IIFE wrapper before the payload is encrypted. Control Flow Flattening then turns eligible function bodies into randomized state machines with decoy states. The legacy Bytecode VM is off by default because phone executors differ in their Luau bytecode support; executor and mobile builds always use the source path. Anti-Tamper checks the payload checksum before it is loaded. Lua 5.1/5.4 targets keep the source wrapper.
